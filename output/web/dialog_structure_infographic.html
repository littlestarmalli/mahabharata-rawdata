Legend & Hierarchy
Level 0 — Narration
Author's voice / frame intro
Level 1 — Speech (Primary)
Souti / Vaishampayana frame
Level 2 — Speech (Character)
Character dialog within frame
Level 3 — Inner Speech
Quote within a quote
Level 4+ — Deeper
Further nested quotes

Nesting Rules

  • Narration contains speech blocks
  • Speech can contain inner speech
  • Quote marks alternate: ' → " → ' → "
  • Each level = one deeper quote
  • Parent-child hierarchy forms a tree
  • Text after inner quote closes still belongs to the parent speech

Quote Depth Pattern — How ' and " Alternate
Depth progression:
Depth 0: plain text ← author narration
Depth 1: '...text...' ← single quotes
Depth 2: "...text..." ← double quotes
Depth 3: '...text...' ← single again
Depth 4: "...text..." ← double again
Key insight:

The Mahabharata text uses curly quotes as structural markers:

\u2018 opens depth +1 (single)
\u2019 closes depth −1 (single)
\u201c opens depth +1 (double)
\u201d closes depth −1 (double)

Every opening quote pushes a new speech depth. Every closing quote pops back to the parent. Text between inner close and outer close is still the parent's speech.
